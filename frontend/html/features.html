Everything You Need

Feature coverage across capture, summarization, playback, and storage

The project combines core content workflows with the implementation details needed for a realistic full-stack build.

Web Scraping

Submit any public URL and extract meaningful text with Cheerio on the backend.

File Upload

Support PDF, DOCX, and TXT uploads with client-side parsing hooks for PDF.js and Mammoth.js.

AI Summaries

Generate concise, storage-friendly summaries through the Gemini API.

Text To Speech

Convert full text or summaries into chunked speech with voice selection and playback controls.

Cloud Storage

Persist metadata in MongoDB Atlas and save final audio URLs in Cloudinary.

Dashboard Analytics

Surface recent activity, usage metrics, and saved content history in one place.

Comparison Demo

Switch between reading and listening modes

Article mode

Ideal when the exact wording matters. Users can inspect longer source material, review structure, and then decide whether to save the full text for later playback.

Summary mode

Best when the goal is speed. The user can reduce thousands of words to a smaller listening session before generating audio.

Voice Preview

Organized voice selection for different audiences

US Voices

Balanced default choices for product demos, tutorials, and day-to-day summaries.

Example: en-US-AriaNeural, en-US-GuyNeural

UK Voices

Useful when the content tone should feel editorial, polished, or presentation-ready.

Example: en-GB-SoniaNeural, en-GB-RyanNeural

India Voices

Helpful for regional listening experiences and localized delivery.
