About The Project

Built as a focused hub for research, summarization, and listening

CIH is designed as a modular project where each layer has a clear responsibility: the frontend handles the experience, the backend orchestrates processing, and MongoDB Atlas stores the working history.

Mission

Make dense content easier to move through

Instead of forcing users to juggle separate tools for scraping, reading, note-taking, and playback, the project pulls those actions into one focused workflow.

  • Capture from multiple source types URLs, PDFs, DOCX files, and TXT uploads all feed the same pipeline.
  • Choose the right listening mode Users can convert either the full text or a concise summary into speech.
  • Persist everything that matters Metadata, saved summaries, and cloud audio links stay connected.

Milestones

Planned build sequence for the full project

  1. Phase 1 Generate the shared frontend shell and the ten-page information architecture.
  2. Phase 2 Wire controllers, models, and routes into an MVC Express backend.
  3. Phase 3 Attach Gemini summarization, TTS chunking, and WebSocket streaming.
  4. Phase 4 Save content records and cloud audio references into MongoDB Atlas and Cloudinary.
